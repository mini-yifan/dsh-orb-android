# v0 验收

> 手机悬浮球先按第 1 节独立验收，入网后再按第 2 节验收。

### 7.2 Android 悬浮球（第二段）

| # | 验收 | 通过条件 |
|---|---|---|
| 1 | 悬浮球 | 全局悬浮，可拖动/停靠 |
| 2 | 长按语音 | 长按录音/波形；松手发送；上滑取消；另一个 App 在前台时也能录 |
| 3 | 发送截图 | 发送时附带当前屏截图，不含球/面板；安全页不截，只发文字 |
| 4 | 精简工具集 + 手机 CU | 悬浮球 Agent 只有 Shell、网页检索与抓取、向用户提问、手机操控和派后台工具（派其他设备的工具在入网后才加）；能对当前屏点按/输入/滚动；敏感确认；可停止 |
| 5 | 面板 | 对话/工具状态/停止/历史/新建 |
| 6 | 后台 Agent | 派给本机标准模式后台任务，完成后回到 Orb，App 不在前台也有通知 |
| 7 | 兼容 | 继承 dsh-Go 支持的 Android 版本/ABI |

### 7.3 手机入网（第三段）

| # | 验收 | 通过条件 |
|---|---|---|
| 1 | 配对与可见 | 手机在互联页粘贴配对串或扫码、点「连接」即接入，不重启引擎；所有电脑的 Mesh UI 看到手机的工作区/会话 |
| 2 | 手机看电脑 | 手机 App 里看到所有电脑的树；能打开远程会话、看实时、输入、停止、答审批 |
| 3 | 手机派电脑 | 手机悬浮球把任务派给 Windows，结果回到手机悬浮球 |
| 4 | 电脑取手机文件 | Mac 让手机找一张照片作为附件取回，显示来源 |
| 5 | 手机屏幕保护 | 默认其他设备派来的任务调不了手机屏幕操作；开关打开后手机有明显提示，敏感操作仍在手机上确认 |
| 6 | 规模 | 5 台同时在线时，上面各项与 7.1 各项都正常 |
