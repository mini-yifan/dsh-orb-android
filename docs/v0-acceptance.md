# v0 验收

> 手机悬浮球先按第 1 节独立验收，入网后再按第 2 节验收。
> 本文是 dsh-orb-cordis 仓库 `docs/16-v0-plan.md` 第 7.1–7.3 节的同步副本（2026-11-11）；与 16 冲突时以 16 为准。

## 7.1 电脑互联

### 7.1.1 两机（第一段）

| # | 验收 | 通过条件 |
|---|---|---|
| 1 | 配对接入 | 两台全新安装的电脑，只在设置页粘贴配对串、点「连接」，不改配置、不重启，15 秒内显示已连接与对端；错误指纹、用过的码、过期的码被拒并给出可读原因 |
| 2 | 树与状态 | Mesh UI 显示「本机 + 对端 → 工作区 → 会话」；状态变化实时可见；对端离线 30 秒内可见 |
| 3 | 看 | 打开任意对端会话，消息/工具/状态实时更新 |
| 4 | 任务会话可交互 | 任务会话能发新指令、能停止当前这一轮，停止后不再动作；对非任务会话调 `prompt` 返回 `session_not_remote_controllable`，UI 输入框置灰 |
| 5 | 跨设备 Agent | Mac 悬浮球派任务给 Windows 标准后台 Agent，结果回到 Mac |
| 6 | 文件 | Mac 发文件给 Windows；Windows 的结果文件回到 Mac，作为该任务附件显示来源与本机路径，有进度 |
| 7 | 改名与离线 | 当前设备改名各端同步，其他设备与管理页只读；目标离线时不派发 |
| 8 | 安全 | 全链路 TLS + E2E，中继流量看不出会话明文；管理页不在公网；无账号登录 |

### 7.1.2 三台电脑全量（第二段）

| # | 验收 | 通过条件 |
|---|---|---|
| 1 | 服务器/管理页 | 阿里云 Linux 可连；经 SSH 隧道打开管理页；管理员口令登录；添加设备/生成配对码 |
| 2 | 配对 | 每台电脑全新安装后，只在设置页粘贴各自的配对串、点「连接」，不改配置、不重启，15 秒内显示已连接和其他设备；重复/过期码、错误指纹被拒，并给出可读原因 |
| 3 | 设备状态 | 管理页看到 3 台设备名/平台/在线/上次在线 |
| 4 | Mesh 树 | 每台电脑 Mesh UI 显示「本机 + 其他所有设备 → 工作区 → 会话」 |
| 5 | 实时会话 | 打开任意对端会话，消息/工具/状态实时更新 |
| 6 | 输入/停止 | 任务会话能发新指令；能停止当前这一轮，停止后不再动作；非任务会话只读 |
| 7 | 跨设备 Agent | Mac 悬浮球派任务给 Windows 标准后台 Agent，结果回 Mac；同时派另一个给第三台 |
| 8 | 审批/提问 | 远程任务的审批与提问能在发起设备答；目标设备也能答，先答者生效；**其他设备打开该会话只显示卡片、按钮置灰**；不自动拒绝，等待超过 10 分钟两边各提醒一次 |
| 9 | 文件双向 | Mac 发文件给 Windows；Windows 结果文件回到 Mac，作为该任务附件显示来源与本机路径，有进度 |
| 10 | 改名/离线/撤销 | 当前设备改名各端同步；其他设备只读；离线 30 秒内可见；离线时不派发；撤销后不能连 |
| 11 | 安全 | 全链路 TLS + E2E；服务器看不到会话明文；管理页不对公网开放 |
| 12 | 无登录 | 没有账号注册/登录页；只有管理员口令/设备配对 |
| 13 | 体验 | Mesh 窗口中英文案、跟随系统深浅色；只用键盘能选中会话并发出一条指令 |

> 验收用文本或 Markdown 文档。标准模式没有图形界面工具，改不了 Word/Excel 里的样式。

## 7.2 Android 悬浮球（第三段）

| # | 验收 | 通过条件 |
|---|---|---|
| 1 | 悬浮球 | 全局悬浮，可拖动/停靠 |
| 2 | 长按语音 | 长按录音/波形；松手发送；上滑取消；另一个 App 在前台时也能录；**松手后 1 秒内出现「转写中」，3 秒内出文字或失败原因** |
| 3 | 发送截图 | 发送时附带当前屏截图，不含球/面板；安全页不截，只发文字；**面板显示缩略图；发送前可上滑取消；重来用「停止这一轮」再发** |
| 4 | 精简工具集 + 手机 CU | 悬浮球 Agent 只有 Shell、网页检索与抓取、向用户提问、手机操控和派后台工具（派其他设备的工具在入网后才加）；能对当前屏点按/输入/滚动；敏感确认；可停止 |
| 5 | 面板 | 对话/工具状态/停止/历史/新建；中英文案 |
| 6 | 后台 Agent | 派给本机标准模式后台任务，完成后回到 Orb，App 不在前台也有通知 |
| 7 | 兼容 | 继承 dsh-Go 支持的 Android 版本/ABI；TalkBack 不设验收（只补 `contentDescription`） |

## 7.3 手机入网（第四段）

| # | 验收 | 通过条件 |
|---|---|---|
| 1 | 配对与可见 | 手机在互联页粘贴配对串或扫码、点「连接」即接入，不重启引擎；所有电脑的 Mesh UI 看到手机的工作区/会话 |
| 2 | 手机看电脑 | 手机 App 里看到所有电脑的树；能打开远程会话看实时；**任务会话**能输入、停止；审批与电脑同一规则（发起设备 + 目标本机） |
| 3 | 手机派电脑 | 手机悬浮球把任务派给 Windows，结果回到手机悬浮球 |
| 4 | 电脑取手机文件 | Mac 让手机找一张照片作为附件取回，显示来源 |
| 5 | 手机屏幕保护 | 默认其他设备派来的任务调不了手机屏幕操作；开关打开后手机有明显提示，敏感操作仍在手机上确认 |
| 6 | 规模 | 5 台同时在线时，上面各项与 7.1.2 各项都正常 |
